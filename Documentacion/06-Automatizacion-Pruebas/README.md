# Automatizacion de pruebas - Semana 12

Este bloque documenta la propuesta inicial de automatizacion de pruebas para `Sistema-ArteyMetal`, usando Python y enfocandose primero en los flujos criticos ya implementados.

## Objetivo

La propuesta no busca automatizar todo el sistema desde el inicio. Busca automatizar primero los flujos de mayor riesgo para el negocio y mayor frecuencia de uso:

1. inicio de sesion
2. gestion de clientes
3. registro de pedidos
4. ventas directas
5. cierre de pedidos
