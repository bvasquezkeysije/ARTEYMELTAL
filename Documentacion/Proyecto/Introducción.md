# Introduccion del proyecto

Arte y Metal Chiclayo E.I.R.L. es una microempresa dedicada a fabricar y comercializar productos metalicos personalizados para clientes particulares, empresas e instituciones.

## Que vende la empresa

- medallas
- trofeos
- solaperos
- reconocimientos
- sherifs
- placas recordatorias
- grabados y otros productos personalizados

## Para que existe el sistema

El sistema centraliza:
- clientes
- productos
- inventario
- pedidos personalizados
- ventas
- reportes
- usuarios y permisos

Su objetivo no es solo registrar datos, sino sostener el flujo real de trabajo entre tienda, produccion y almacen.
