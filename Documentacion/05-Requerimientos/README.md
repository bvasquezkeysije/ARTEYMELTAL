# Requerimientos - alcance funcional

Este bloque existe para entender que espera el negocio del sistema y para validar si una funcionalidad nueva entra o no en el alcance actual.

## Lo principal

- autenticacion y recuperacion de acceso
- usuarios, roles y permisos
- clientes con consulta de DNI/RUC
- productos, categorias e imagenes
- stock e inventario
- pedidos personalizados
- ventas y comprobantes
- reportes y exportaciones
- configuracion de cuenta

## Como usar este documento

- Si vas a construir una funcionalidad nueva, revisa si ya existe como RF o HU.
- Si una regla del negocio no aparece en requerimientos, valida si es regla operativa o deuda documental.
- Si una historia contradice el comportamiento actual del sistema, la fuente de verdad operativa es la logica del negocio y luego el codigo.
