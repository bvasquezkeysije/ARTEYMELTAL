# Pruebas funcionales manuales

Esta sección documenta las pruebas manuales ejecutadas por el equipo de QA.

| ID | Caso de prueba | Pasos ejecutados | Resultado |
| --- | --- | --- | --- |
| CP01-HU01 | Inicio de sesión con credenciales válidas | 1) Ingresar al login. 2) Escribir correo y contraseña válidos. 3) Hacer clic en Iniciar sesión. 4) Verificar redirección al dashboard. | Satisfactorio |
| CP05-HU02 | Recuperación de contraseña por código | 1) Ingresar a Olvidaste tu contraseña. 2) Escribir correo registrado. 3) Revisar bandeja de entrada. 4) Ingresar código y nueva contraseña. | Satisfactorio |
| CP08-HU03 | Crear pedido personalizado | 1) Abrir Pedidos > Nuevo. 2) Seleccionar caja abierta. 3) Ingresar cliente y productos. 4) Guardar y verificar código PED-. | Satisfactorio |
| CP12-HU04 | Gestionar flujo de pedido | 1) Abrir pedido en estado sin_iniciar. 2) Derivar a diseño. 3) Aprobar diseño. 4) Derivar a producción. 5) Verificar notificaciones. | Satisfactorio |
| CP15-HU05 | Registrar venta directa | 1) Abrir Ventas > Nuevo. 2) Seleccionar caja abierta. 3) Agregar producto con stock. 4) Registrar pago. 5) Generar comprobante. | Satisfactorio |
| CP18-HU06 | Gestionar productos | 1) Abrir Productos > Nuevo. 2) Completar datos. 3) Subir imagen. 4) Guardar y buscar el producto. | Satisfactorio |
| CP21-HU07 | Gestionar clientes | 1) Abrir Clientes > Nuevo. 2) Ingresar DNI. 3) Consultar RENIEC. 4) Guardar cliente. | Satisfactorio |
| CP24-HU08 | Control de caja | 1) Abrir Cajas. 2) Seleccionar caja cerrada. 3) Ingresar monto inicial. 4) Abrir caja. 5) Registrar venta. 6) Cerrar caja. | Satisfactorio |
| CP27-HU09 | Gestionar almacén | 1) Abrir Almacén > Movimientos > Entrada. 2) Seleccionar producto. 3) Ingresar cantidad. 4) Guardar y verificar stock. | Satisfactorio |
| CP30-HU10 | Consultar reportes | 1) Abrir Reportes > Ventas. 2) Seleccionar fechas. 3) Aplicar filtros. 4) Verificar KPIs y gráficos. | Satisfactorio |
